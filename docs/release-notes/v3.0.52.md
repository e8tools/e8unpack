# v8Unpack 3.0.52

Данные макетов сохраняются отдельными файлами — табличный документ открывается прямо в 1С.

## Макеты: данные отдельными файлами

- **Было:** данные макета лежали составным элементом `<GUID>.0` — ни имени, ни расширения, открыть
  такой файл в 1С нельзя. Ни табличный документ, ни текст макета из дерева не читались.
- **Стало:** данные макета сохраняются отдельным файлом, названным по имени макета, с расширением
  по виду:
  - `<Имя макета>.mxl` — табличный документ. Его нагрузка в контейнере — это ровно содержимое файла
    `.MXL` (сигнатура `MOXCEL` в первых шести байтах), поэтому файл открывается в 1С;
  - `<Имя макета>.txt` — текстовый документ; он байт в байт совпадает с `Ext/Template.txt` из
    выгрузки платформы.
- Вид макета берётся из дескриптора объекта — соседнего элемента `<GUID>`: узел `{2,<код>,}`, где
  `0` — табличный документ, `3` — HTML-документ, `4` — текстовый документ. Коды сверены с выгрузкой
  платформы на конфигурации, где лежат все три вида.
- Макет-HTML оставлен составным элементом как есть: его нагрузка — обёртка `{5,"ru",{#base64:…}}`,
  а не сам `.html`. Вид при этом записан в манифест.
- Пример из дерева: `Общие/Хранилища настроек/ХранилищеНастроек2/Макеты/Макет/Макет.mxl`.

## Обратите внимание

- Деревья `-DE` изменились: у табличных и текстовых макетов вместо `<GUID>.0` теперь
  `<Имя макета>.mxl` и `<Имя макета>.txt`. Если ваши скрипты опираются на прежние имена, их нужно
  поправить.
- Сборка (`-CO`) не менялась: манифест хранит исходное имя элемента контейнера и вид макета
  (`templateKind`), поэтому контейнер собирается как прежде.
- Формат манифеста не менялся — добавлено необязательное поле `templateKind`, манифесты прежних
  деревьев читаются.

## Что проверено

- `1Cv8_mods.cf` (403 члена, макеты всех трёх видов): распаковка → сборка → контрольная распаковка;
  деревья совпадают полностью, список членов 403 = 403.
- Вынесенные данные макетов побайтово равны исходным элементам контейнера — 8 из 8.
- Текстовые макеты побайтово равны `Ext/Template.txt` из выгрузки платформы — 4 из 4.
- Правило «код 0 — табличный документ» проверено на боевой конфигурации: у всех 6001 просмотренного
  макета с этим кодом нагрузка начинается с `MOXCEL`, исключений нет.
- Полученный `.mxl` открыт в 1С — читается как табличный документ.
