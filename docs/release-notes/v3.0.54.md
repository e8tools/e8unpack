# v8Unpack 3.0.54

Сборка крупных конфигураций идёт быстрее: уровень сжатия задаётся опцией, а дерево больше не
копируется целиком.

## Сборка: `--level` и меньше лишнего I/O

- **Новое `--level N` (1..9)** — уровень сжатия zlib для `-CO` и `-BUILD`. По умолчанию
  остаётся 9, как и было: результат сборки байт-в-байт прежний.
- **Было:** deflate всегда работал на `Z_BEST_COMPRESSION`, а `StructuredPacker` копировал все
  файлы дерева в `.tmp_pack` перед сборкой — на дереве 3,7 ГБ это лишние гигабайты чтения и
  записи на каждой сборке.
- **Стало:** уровень сжатия — параметр; в `.tmp_pack` ставятся жёсткие ссылки на файлы дерева
  (если ссылку создать нельзя — обычное копирование). Сборщик эти файлы только читает, входное
  дерево не изменяется.

Замеры на боевой конфигурации (762 МБ, 78 844 члена, дерево 3,7 ГБ / 86 046 файлов, 2 ядра):

- `-CO` уровень 9 (по умолчанию): **619,9 с**, 753 582 285 Б
- `-CO` уровень 6: **389,8 с**, 762 282 516 Б (+1,15 % размера)

То есть уровень 6 собирает на 37 % быстрее. На сборку этой конфигурации теперь уходит примерно
на 2,4 ГБ меньше записи и на 2,8 ГБ меньше чтения с диска.

## Обратите внимание

- Без `--level` поведение не изменилось: сборка даёт тот же байт-в-байт результат, что и 3.0.53.
- Уровень ниже 9 меняет размер контейнера. Если у вас в CI зафиксирован sha256 собранного
  контейнера, обновляйте эталон осознанно — либо просто не указывайте `--level`.
- Формат контейнера, раскладка дерева и формат `manifest.json` не менялись: деревья,
  распакованные прежними версиями, собираются этой версией без пересборки.

## Что проверено

- Уровень 9 после правки: сборка BP (762 МБ) дала прежний sha256 `2ce5f3b6…` и прежний размер
  753 582 285 Б; на `1Cv8_mods.cf` (403 члена) — прежний эталон `5f035387…`.
- Уровень 6: контейнер разбирается обратно в побайтово то же дерево — отличается только поле
  `createdAt` в `manifest.json`.
- Ссылки вместо копий: отпечаток состава дерева до и после сборки совпадает (86 046 файлов),
  `.tmp_pack` удаляется, собранный контейнер не меняется.
- Неверное значение `--level` (например, 12): предупреждение в stderr, сборка идёт на значении
  по умолчанию.
- Расширение `Спецификатор.cfe` (351 член): раскладка по каталогам типов, сборка и контрольная
  распаковка — как в 3.0.53, без расхождений.
